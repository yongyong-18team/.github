# 돌봄바통

> 일기로 남긴 일상이, 다음 돌봄을 위한 설명서가 됩니다.
> 돌봄이 사라지지 않고, 다음 사람에게 이어지도록.

**돌봄바통**은 발달장애인 보호자가 매일 쓰는 돌봄 일기를 AI가 정리하고, 보호자가 승인한 정보만 모아 "이 사람을 돌보는 법" 설명서로 만들어 다른 돌봄 제공자에게 링크 하나로 넘겨주는 AI 기반 돌봄 인수인계 서비스입니다. 돌봄을 이어달리기의 바통처럼 안전하게 넘겨주는 것을 목표로 합니다.

## 왜 만들었나

발달장애인의 습관, 불안해하는 상황, 진정시키는 방법은 주 보호자의 머릿속에만 있는 경우가 많습니다. 보호자가 입원하거나 활동지원사가 바뀌면 이 정보가 끊기고, 그 공백이 곧 돌봄 공백이 됩니다. 구두나 메신저로 매번 다시 설명하면 중요한 정보가 빠지기 쉽습니다.

돌봄바통은 **기록 → 정리 → 공유**의 흐름으로 이 공백을 줄입니다. 첫 대상은 용인시에 거주하며 개별적인 돌봄 지원이 필요한 발달장애인을 주로 돌보는 보호자입니다.

## 이렇게 동작합니다

1. **기록**: 보호자가 그날의 돌봄을 음성이나 텍스트로 일기에 남깁니다.
2. **정리**: AI가 일기에서 행동, 불안 요인, 대처법, 복약 같은 항목을 뽑아 제안합니다.
3. **승인**: 보호자가 항목을 확인하고 반영할 것만 승인합니다. AI는 제안만 하고, 결정은 보호자가 합니다.
4. **설명서**: 승인한 정보가 돌봄 설명서에 쌓입니다.
5. **공유**: 보호자가 공개할 내용을 골라 링크를 만들면, 받는 사람은 로그인 없이 열람합니다. 링크는 7일 뒤 만료되고, 보호자가 언제든 막을 수 있습니다.

## 핵심 가치

- **보호자가 정합니다**: 설명서와 공유 문서에는 보호자가 승인했거나 직접 입력한 정보만 들어갑니다.
- **필요한 만큼만 공유합니다**: 공개할 섹션을 보호자가 고르고, 공유 링크는 승인 시점의 내용으로 고정됩니다.
- **보호자도 돌봅니다**: 소진 신호가 쌓이면 휴식·상담 제도를 안내하고, 위기 표현이 있으면 안전 안내를 먼저 보여줍니다.
- **지역 자원과 이어집니다**: 단기·장기, 날짜, 지역 조건으로 용인시 돌봄 시설과 지원 제도를 찾아볼 수 있습니다.
